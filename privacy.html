Privacy Policy

Els Issue Uploader · Effective date: November 13, 2026

1. Overview

Els Issue Uploader ("the Tool") is an internal, single-user application operated by the owner of the YouTube channel "엘's 이슈 (Els Issue)". The Tool is not publicly available, and the channel owner is its only user.

2. Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool, the user agrees to be bound by the YouTube Terms of Service. The use of YouTube API Services is also subject to the Google Privacy Policy.

3. Information accessed

  • Authorization tokens: OAuth 2.0 tokens issued by Google that let the Tool act on the owner's own channel.
  • Channel data: basic information about the owner's own channel, the videos the owner uploads through the Tool, and analytics for the owner's own channel (for example, views and audience retention).

The Tool does not access data of any other YouTube user or channel.

4. How information is used

  • To upload videos produced by the owner to the owner's own channel and set their metadata and publish schedule.
  • To read the owner's own channel analytics to improve future content.

5. Storage

Authorization tokens and analytics data are stored only on the owner's own computer (and, if used, the owner's private storage). They are not sold, shared with, or disclosed to any third party.

6. Sharing

No information obtained through YouTube API Services is shared with third parties.

7. Cookies

The Tool is not a public website and does not place cookies on visitors' devices. This page itself does not use cookies or tracking.

8. Revoking access and deleting data

Access granted to the Tool can be revoked at any time through the Google security settings page. When access is revoked, the locally stored tokens are deleted, and stored analytics data is deleted within 30 days.

9. Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
